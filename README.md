# React + Vite

FRONTEND

El sistema Suite de Gestión de Portadores Energéticos, es una aplicación web que permitirá que las empresas puedan llevar a cabo la planificación y control del uso de los portadores energéticos mediante un sistema informático capaz de consolidar la información y procesar las tareas necesarias para la distribución y control de los portadores energéticos.

Instalar dependencias

Abrir la terminal de comandos y ejecutar: npm install.

Ejecutar

Abrir la terminal de comandos y ejecutar: npm run dev.

Luego de que se ejecute correctamente el comando, va a salir en consola el servidor de Vite. Para abrir la página en el navegador escribe la letra o y presiona Enter. Para abrir la ayuda escribe h y presiona Enter. Para cerrar el servidor escribe q y presiona Enter (también sirve presionar Ctrl + C).
